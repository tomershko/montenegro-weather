# Montenegro Weather 🇲🇪

מלווה לטיול הג׳יפים במונטנגרו, **23–30 בספטמבר 2026**, בעברית ובתצוגה מותאמת לנייד.

## מה באתר

- תצוגת ״מה חשוב עכשיו״: הכנות וטיסה לפני הטיול, ופרטי היום במהלך הטיול.
- מסלול יומי עם פרטים נפתחים, מקומות לינה וקישורי ניווט ליעדים.
- תחזית לפי מיקום ותאריך: טמפרטורות, סיכוי לגשם, משקעים ומשבי רוח.
- סיכום הימים הקרים, החמים והגשומים ביותר מבין התחזיות הזמינות.
- פרטי טיסות מתוכננים וקישור חיצוני לבדיקת סטטוס טיסה.
- רשימת ציוד המשלבת המלצות מחוברת Tripology עם התאמות למסלול ולתחזית.
- סימון פריטים שנארזו ונקודות המציינות באילו ימים כל פריט שימושי.

## הפעלה ופיתוח

האתר בנוי בקובץ `index.html` הכולל HTML, CSS ו־JavaScript, ללא שלב build או התקנת חבילות.

להרצה מקומית, מתוך תיקיית המאגר:

```sh
python3 -m http.server 8000
```

לאחר מכן פותחים את [האתר המקומי](http://localhost:8000).

לעדכון התוכן עורכים את `index.html`:

- `itinerary` — תאריכים, מסלול, לינה, טיסות ויעדי ניווט.
- `locations` — שמות ונתוני מיקום לתחזית.
- `buildGear` — רשימת הציוד וכללי ההתאמה לימים ולמזג האוויר.
- `renderNow` — תצוגת המידע הרלוונטי לפני הטיול ובמהלכו; פרטי הטיסה שלפני הטיול מוגדרים גם כאן.

## מקורות נתונים ושמירה

התחזית מגיעה מ־[Open-Meteo](https://open-meteo.com/) ומתעדכנת בטעינת העמוד, ברענון ידני ובכל 30 דקות כשהעמוד פתוח. ימים שמחוץ לטווח התחזית מוצגים ללא נתוני מזג אוויר עד שהתחזית זמינה.

המסלול והמלצות הציוד שבאתר מבוססים על חוברת Tripology לטיול. פרטי הטיסות מוגדרים בקוד; סטטוס טיסה חי נבדק באמצעות קישור חיצוני ואינו נטען אוטומטית לאתר.

סימוני האריזה ועותק התחזית האחרון נשמרים ב־`localStorage` בדפדפן. הסימונים אינם מסתנכרנים בין מכשירים, והתחזית השמורה משמשת כגיבוי אם עדכון הנתונים נכשל.

## ממשק ומפות

הניווט התחתון מחלק את האתר להיום, מסלול וציוד. במסלול ניתן לבחור יום ותחנה ולהציג מפת Google Maps של המקום. המפה מבוססת על חיפוש לפי שם ואינה תוואי נסיעה מאומת או מפת שטח.

## שימוש ללא קליטה

`sw.js` שומר את עמוד האתר לאחר פתיחה מוצלחת דרך HTTPS (או localhost). יש להמתין להודעה שהאתר מוכן ללא קליטה לפני היציאה. המסלול והציוד נשארים זמינים; מפות, ניווט ונתונים חדשים דורשים אינטרנט. תחזית שמורה מוצגת עם זמן העדכון המקורי. מחיקת נתוני הדפדפן מוחקת גם את השמירה המקומית.

## גלויות ל־24 שעות

`postcard.html` מכיל יצירת גלויה, תצוגה מקדימה, מעטפה אינטראקטיבית והקדשה. הקישור נמצא באזור המידע באתר. התמונה מוקטנת במכשיר לפני העלאה; אין שמירת תמונות אישיות ב־GitHub.

השיתוף דורש חיבור לשרת Supabase לפי [הוראות ההפעלה](supabase/README.md). כל עוד כתובת השירות ב־`postcard-config.js` ריקה, ניתן לעצב ולראות תצוגה מקדימה אך לא לפרסם קישור. השרת אוכף תפוגה קבועה של 24 שעות ושומר את התמונות באחסון פרטי, עם ניקוי מתוזמן.
